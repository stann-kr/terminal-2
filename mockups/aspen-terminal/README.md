# TERMINAL — Aspen 격자 목업

검정·오렌지, TERMINAL 워드마크 전용 Pixie와 본문/제목 Orbit 서체, 화면 전체 CRT 유리와 고정 header/footer를 유지하는 독립 목업입니다. 4열 기준선으로 Home, Gate, Lineup, Guest Request, Status, Transmit, Signal, About, Link를 구성합니다.

## 실행

저장소에서 설치한 기존 React/esbuild와 lockfile을 사용합니다. 새 의존성은 없습니다.

```sh
node mockups/aspen-terminal/build.mjs
node mockups/aspen-terminal/build.mjs --serve
```

- 생성 파일: `mockups/aspen-terminal/dist/index.html`. 폰트·CSS·JS가 포함되어 파일만 열어도 동작합니다.
- 로컬 주소: `http://127.0.0.1:3005`. 이미 사용 중인 3005 서버를 자동 종료하거나 다른 포트로 변경하지 않습니다.
- 직접 진입: `#/home`, `#/gate?event=TRM-02`, `#/lineup?event=TRM-01&artist=01-B`, `#/gate/request`, `#/signal` 등. 제품 URL을 바꾸지 않는 목업 내부 hash입니다.
- 터미널 체험: `#/entry`. 처음은 부팅, 부팅을 완료한 다음 방문은 IDLE입니다. 소개의 **터미널 체험**에서도 들어갈 수 있습니다.
- 검토 옵션의 **부팅 다시 보기** / **IDLE 화면 보기**, 또는 `#/entry?mode=boot` / `#/entry?mode=idle`로 방문 기록과 관계없이 해당 화면을 확인합니다.
- 수정 후 첫 명령으로 다시 빌드하고 새로고침합니다. 생성물은 ignored `dist/`에만 둡니다.

## 검토 범위

상단 **검토 옵션**에서 지난 행사, 접수 기간 가정, 진행 중 가정, 공개 행사 없음, 데이터 오류, 긴 제목을 선택합니다. 포스터 분기는 본인 로컬 이미지를 선택해 확인합니다. 이미지 오류는 회차 구성으로 돌아갑니다.

### 화면 높이와 스크롤

- 특수 Pixie 서체는 브랜드 단어 `TERMINAL`에만 적용합니다. 혼합 제목은 해당 단어만 분리하며, 타이핑 출력도 같은 서체 구분을 유지합니다. 아티스트명·메뉴·폼 제목은 Orbit, 카운트다운과 날짜 숫자는 일반 고정폭 서체를 사용합니다.

- 고정 프레임에서 헤더·메뉴·푸터를 제외한 실제 본문 영역을 기준으로 높이를 채웁니다. 제목·여백·입력 영역은 본문 높이에 맞춰 조정합니다.
- 긴 내용이나 세로로 쌓이는 모바일 화면은 본문 안에서 스크롤합니다. 내용을 잘라 숨기거나 폼의 접근을 막지 않습니다.

### 부팅과 언어

- 부팅·IDLE에는 헤더/메뉴/OS 푸터/목업 검토 도구를 표시하지 않습니다. 진입 버튼을 눌러 입장한 뒤 나타나며, 언어와 CRT 설정은 진입 후 변경할 수 있습니다.
- 같은 CRT 프레임에서 전원 표현 → 콘솔 출력·언어 자동 감지 → **터미널 입장 / ENTER TERMINAL** → 홈으로 이어집니다. 언어 선택을 기다리는 단계는 없습니다. 부팅 출력은 시각 연출이며 서버 연결 검사를 뜻하지 않습니다.
- 언어는 **저장된 수동 선택 → 브라우저 선호 언어 목록에서 첫 KO/EN → 영어** 순으로 결정합니다. `navigator.languages`가 비어 있으면 `navigator.language`를 사용합니다. 웹에서 직접 제공하지 않는 OS 설정을 별도 추정하지 않습니다.
- 상단 KO/EN 전환은 수동 선택으로 저장합니다. 자동 감지 결과는 고정 저장하지 않으므로 브라우저 선호 언어가 달라지면 다음 로드에 반영됩니다.
- 부팅은 약 3초 동안 화면의 얇은 빛이 펼쳐진 뒤, 로그 출력과 결과 대기·짧은 묶음 출력을 거쳐 준비 커서로 이어집니다. 상태 커서는 출력된 마지막 항목 바로 아래를 따라 내려가고, 완료 후 **SYSTEM READY.** 아래에 입장 버튼을 표시합니다. 왼쪽 **TERMINAL**은 한 줄로 가운데 정렬합니다.
- **애니메이션 건너뛰기**는 연출만 완료합니다. 완료 후 폭 최대 320px·높이 64px의 **터미널 입장 / ENTER TERMINAL** 버튼 하나를 표시하며, 이 버튼을 눌러야 홈으로 이동합니다. 기존 홈/상세 직접 URL은 유지됩니다.
- reduced-motion, CRT OFF, 숨겨진 문서, 데이터 절약에서는 부팅 연출을 완료 상태로 전환합니다. 이후 설정을 되돌려도 부팅을 다시 시작하지 않습니다. IDLE 시계는 실제 KST이며 숨겨진 문서에서는 타이머를 멈춥니다.
- 목업 전용 `terminal_aspen_preview_entry_v1`에 방문 완료 여부와 직접 선택한 언어만 저장합니다. 기존 제품의 방문/언어 키와 폼 내용은 사용하지 않습니다. 저장소 차단 시 현재 탭 메모리로 동작합니다.

### 행사와 입력

- 홈 상단은 행사명 2칸·회차(또는 포스터) 1칸·카운트다운 1칸으로 나눕니다. 카운트다운은 독립 구획 안에서 일·시간·분·초를 2×2로 표시합니다. 모바일은 행사명 아래에 회차와 카운트다운을 나란히 배치합니다. 행사 시작 시각은 KST 기준입니다. 시작 전은 `T− COUNTDOWN`, 시작 후는 `T+ ELAPSED`이며, 후자는 행사 시작 이후의 경과 시간입니다. 행사 종료 시각을 추정하지 않습니다. 접수 가정은 2026-05-01부터 흐르는 체험 시계임을 표시합니다. 초 단위 시계는 일반 본문 출력과 분리하고, 숨겨진 탭에서는 갱신을 멈춘 뒤 복귀 시 동기화합니다.
- 상단 이벤트·라인업·게스트 신청 메뉴는 현재 선택한 행사 ID를 유지합니다.

- 기본 데이터는 2026-09-15 로컬 D1의 행사·아티스트 공개 필드 스냅샷입니다. 제품 lifecycle 규칙과 기준 시각을 적용해 과거 날짜의 UPCOMING도 지난 행사로 표시합니다. 운영 서비스의 현재 상태는 아닙니다.
- 공개 이름은 `CONFIRMED`/`ARCHIVED` 상태로 판단합니다. 기본 아티스트는 URL이나 focus를 자동으로 변경하지 않습니다. 잘못된/미공개 artist URL은 별도 안내합니다.
- 접수 가정은 2026-05-01 기준 TRM-02 신청 화면입니다. 체험 코드는 `DEMO02`. 실제 코드 검증이나 초대 권한이 아닙니다.
- 신청·소식은 필드/동의 확인, 제출 중, 실패 후 재시도, 결과, 화면 이동 후 초안 유지를 제공합니다. 실제 API/인증/중복 경쟁/영속 저장과 연결하지 않습니다. 행사·기간 변경은 코드 확인을 해제하고 진행 중 결과를 취소합니다.
- 방명록은 빈 상태로 시작합니다. 작성 글은 메모리에만 추가되며 검토 옵션의 7개 예시는 명시적으로 구분합니다. 페이지 실패 후 현재 글/초안과 이전 페이지 복귀를 유지합니다.
- 입력은 서버에 전송되지 않습니다. CSP의 `connect-src 'none'`과 `form-action 'none'`으로 네트워크 전송을 막습니다. 새로고침하면 초안과 결과가 초기화됩니다. 공식 외부 링크는 새 탭에서 열립니다.

### 모션과 전환

- 페이지 구획·격자선·버튼·입력칸도 출력 순서에 포함합니다. 최종 공간을 미리 확보한 채 각 구획이 한 번에 켜지고, 그 안의 제목·본문·메타 정보·명단·폼 안내·버튼 문구가 이어서 출력됩니다. 선을 따라 흐르는 효과나 위치 이동은 없습니다. 브라우저의 실제 줄바꿈 위치를 측정하며, 각 영역 안에서 위→아래·같은 높이는 왼쪽→오른쪽 순으로 표시합니다. 모든 페이지에서 구획 간격은 65ms, 본문은 한 줄당 45ms, 제목 문자 출력은 한 글자당 12ms로 동일합니다. 전체 시간 제한 없이 내용이 많은 페이지는 그만큼 오래 출력됩니다.
- 원문과 접근 가능한 이름은 출력 중에도 유지합니다. 제목은 별도의 장식 레이어에 문자를 쓰고, 본문은 완성된 배치를 유지한 채 줄 단위로 표시합니다. 클릭·키보드·휠 스크롤·입력을 시작하면 모든 본문 영역의 남은 출력을 즉시 끝냅니다. 창 크기나 폰트가 바뀌어도 원문 전체를 바로 표시합니다.
- 부팅 후 입장에는 CRT 화면의 짧은 발광과 메뉴 표시를 연결합니다. IDLE은 처음 표시할 때만 재생하며 시계의 매초 갱신에는 모션을 반복하지 않습니다.
- 라인업 선택, 방명록 페이지/새 글, 코드 확인·오류·접수 결과는 각 영역에서 갱신합니다. 폼 입력 중에는 초안을 유지하며 오류·상태·결과만 다시 출력합니다. 버튼·링크는 고정된 위치에서 기존 색상과 반전 상태로 반응합니다.
- 처리 중에는 버튼 문구 옆의 블록 커서가 깜박입니다. 화면을 떠나거나 CRT OFF·동작 줄이기·데이터 절약·숨겨진 탭 상태가 되면 진행 중인 장식 모션을 정리합니다. 숨겨진 탭으로 돌아오거나 설정을 복구하는 것만으로 페이지 진입 연출을 재시작하지 않습니다.
- `motion/`이 목업 전용 GSAP 등록·모션 정책·공통 문자 출력과 처리 중 커서를 맡고, 각 화면이 대상 요소와 재생 시점을 지정합니다. 실제 라우팅·focus·입력·접수 상태는 애니메이션 완료를 기다리지 않습니다.

## 소유 범위

`shell/`은 고정 프레임·메뉴·CRT, `entry/`는 부팅·IDLE·언어 감지·방문 기록, `events/`는 스냅샷·홈·상세, `lineup/`은 선택과 소개, `forms/`는 신청·소식, `transmit/`은 방명록, `info/`는 기록·소개·링크를 맡습니다. 각 화면의 스타일은 해당 폴더에 둡니다. 실제 Next route, API, DB, 공통 디자인 토큰, migration/patch는 변경하지 않습니다.
